以下的測試程式碼皆可直接在 node 環境中貼上執行，直接在終端機(ex: iTerm)中下 node 即可進入環境，另外也可以貼到 Chrome 的 Console(按 F12)。

過濾陣列重複的值

MDN 解釋: Set objects are collections of values. You can iterate through the elements of a set in insertion order. A value in the Set may only occur once; it is unique in the Set's collection.

簡單來說: 會把重複的值過濾掉讓它(value)只出現一次，並創建一個新的陣列

const tmp = [1, 1, 1, 2, 2, 3, 4, 5, 6, 6, 6, 7];
new Set(tmp);
//result: Set { 1, 2, 3, 4, 5, 6, 7 }

轉換成 Boolean

!5;
//false
!"5";
//false
![];
//false
!{};
//false
!"";
//true

強制型態轉換

以下提供常見與 JavaScript 提供的另一種方法:

字串 與 整數 互換

const b = 123; // Integer
// 轉字串
String(b); // '123'
b + ""; // '123'

// 字串轉整數
const c = "456";
Number(c); // 456
+c; // 456

// 整數 -> 字串 -> 整數
Number(String(b)); // 123
+(b + ""); // 123

浮點數 與 整數

更多使用方法可以參考 stackoverflow

const d = 123.45;
parseInt(d); // 123
d | 0; // 123
~~d; //123
>>d; //123

陣列長度修改

這個使用方式會更改到原本的陣列

const arr = [1, 2, 3, 4, 5, 6];
arr.length = 3;
// [1, 2, 3]

若不想更改到原本的陣列可以使用 filter 來操作:

arr.filter((el) => arr.indexOf(el) < 3);

常見函式呈現方法

function campaign1() {
  console.log("Hello 1 world");
}

const campaign2 = function () {
  console.log("Hello 2 world");
};
const campaign3 = () => console.log("Hello 3 world");

// 特定需求像是: 遞迴
const campaign4 = function fac(n) {
  return n < 2 ? 1 : n * fac(n - 1);
};
console.log(campaign4(3));

在操作上若要宣告當下就執行，可以參考 「IIFE」
