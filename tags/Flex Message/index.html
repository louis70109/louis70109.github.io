2022-02-03 · LINE

【Flex Message】部署與共用屬於你的 Flex Message API

他怎麼出現的？

當時因為公司、社群、工作坊以及各種朋友群組都會需要分享各種活動資訊，包括活動告知、訂位消息、個人資訊卡、新聞...而每個需求中都剛好包含著其他功能 🔧，有時用 JavaScript、有時 Python，而每次寫的 Flex Message 就會散落在各地，東西、時間一多都會忘了當時做的東西在哪 💦，也就浪費當時花費的精力，而且在微服務這麼盛行的現今怎能不切出來呢 🤔
